# 참고 주사위

여기에 참고용 주사위 PNG 를 둡니다.

| 파일 | 내용 |
| --- | --- |
| `blank.png` | 눈이 없는 빈 주사위 |
| `1.png` ~ `6.png` | 윗면에 눈이 하나씩 들어간 주사위 |

넣은 뒤:

```bash
npx tsx tools/build-frames.mts frames
```

`src/core/generate/diceFrames.ts` 가 다시 만들어집니다.

## 규칙

- 모두 **같은 크기**여야 합니다. 섞이면 스크립트가 멈춥니다.
- 배경은 투명이어야 합니다. 흰 배경이면 실루엣이 사라집니다.
- 64x64 로 저장했지만 실제 격자가 32x32 인 그림은 자동으로 32x32 로 되돌립니다.
  경계가 얼마나 정렬돼 있는지로 판정하므로 손대지 않아도 됩니다.
